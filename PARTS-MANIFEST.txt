君主之刃 v2.4.0 · 分卷安裝說明
================================

檔案清單：
  game-code.zip              程式碼與設定 (~810KB)
  assets-part1.zip           遊戲資源第1卷 (24MB)
  assets-part2.zip           遊戲資源第2卷 (24MB)
  assets-part3.zip           遊戲資源第3卷 (~0.7MB)
  ASSETS-FRAME-AUDIT.txt     Sprite 幀數如實盤點報告

安裝步驟：
  1. 解壓 game-code.zip 到目標資料夾
     unzip game-code.zip

  2. 合併 assets 分卷並解壓
     cat assets-part1.zip assets-part2.zip assets-part3.zip > assets-full.zip
     unzip assets-full.zip
     rm assets-full.zip

  3. 啟動服務
     npm start
     # 或直接：node server/server.cjs

  4. 瀏覽器打開 http://localhost:3000

系統需求：
  - Node.js 18+
  - 約 60MB 硬碟空間
  - 建議 2GB RAM

注意：
  - 預設使用檔案式儲存 (server/data/accounts.json)
  - 平台重啟會清空，建議接 Postgres 或掛持久磁碟
  - 設定 DATABASE_URL 環境變數即可切換 Postgres
  - 所有可動單位均為 CSS 動畫節奏（非真 8 幀手繪），
    詳見 ASSETS-FRAME-AUDIT.txt
